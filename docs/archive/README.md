# Documentation archive

Everything below this directory is historical context, not current implementation guidance.

- `adr/` preserves accepted and superseded architectural decision records.
- `legacy-spec/` preserves the former numbered/master/detail documentation structure as it existed before consolidation.
- `completed-tasks/` is reserved for concise completed task specifications and final evidence.
- `verification/` is reserved for dated command/test evidence that should not inflate current architecture documents.

Do not read the archive by default. Current authoritative documentation starts at [`../README.md`](../README.md). If archived text conflicts with current docs, the current docs win unless the owner explicitly supersedes them.
