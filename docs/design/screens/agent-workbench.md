# Agent workbench

The selected agent appears once in a compact selector. Desktop places configuration beside the real test conversation; narrower layouts use `Cấu hình | Thử chatbot` tabs while preserving both drafts.

Configuration covers identity/greeting, behavior, catalog scope, ready knowledge sources, publish state and channel assignments. Editing a published agent creates draft changes; the UI clearly distinguishes draft testing from the active revision.

Playground streams real backend output, supports stop/retry/reset of local test history and renders only validated product cards/source references. It never becomes a shopper conversation. Missing runtime/provider configuration shows an explanatory state rather than a fake reply.

Channel settings show Website, Facebook and Zalo as parts of the same agent/channel model. A connection control appears only when implemented and reports real verification/health. Credentials are write-only and never redisplayed.
